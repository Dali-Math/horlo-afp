# Plan de Recherche - Calibres Horlogers Techniques Suisses

## Objectif
Analyser en profondeur les calibres horlogers techniques suisses les plus prestigieux, incluant leur fonctionnement, spécifications techniques, certificats COSC et finitions.

## Calibres à Analyser
1. **ETA 7750** - Mouvement chronographe universel
2. **Patek Calatrava** - Mouvement classique de référence
3. **Rolex 4130** - Mouvement chronographe propriétaire Rolex
4. **Audemars Piguet 3120** - Mouvement manufacture AP
5. **Jaeger-LeCoultre 889/2** - Mouvement manufacture JLC
6. **Omega 2500** - Mouvement chronographe avec échappement Co-Axial
